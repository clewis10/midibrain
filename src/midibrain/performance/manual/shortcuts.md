# Shortcuts and gestures

Canvas shortcuts apply when focus is not in an input, select or text area. The wiki's own search shortcuts work inside the wiki reader.

## Canvas

| Key or gesture | Result |
| --- | --- |
| F | Fit visible nodes |
| P | Show/hide the docked panel |
| Escape | Return to Edit; clear multi-selection or close the inspector selection |
| Command/Ctrl + Z | Undo a draft/layout edit |
| Command/Ctrl + Shift + Z | Redo |
| Delete / Backspace | Remove a selected wire; offer deletion for a selected MOD |
| Scroll | Pan the canvas |
| Pinch or Command/Ctrl + scroll | Zoom |
| Drag a node header | Move the node, or the selected group |
| Shift-click a node header | Toggle its membership in the multi-selection |
| Shift-drag empty canvas | Box-select nodes |
| Click empty canvas | Clear multi-selection |
| Drag a connection dot to an input | Add a compatible connection |
| Hover a wire or connection | Highlight its endpoints |
| Shift-click Tidy | Rebuild default columns |

## Controls and panels

In Edit, click a control label to inspect its binding. In Perform, drag a value control and release to send; Shift gives finer movement. Keyboard arrows and Home/End operate supported focused value controls in Perform. A button's press/release behavior depends on its assigned action.

Drag a node's right edge to resize it; double-click the edge to reset the width. The focused edge handle supports arrow keys. Resize the dock with its divider or use the focused divider's arrows. Use the dock buttons to move it to another side.

In Inspect, the breadcrumb links and back arrow move through the selection hierarchy. Fold section headings to reduce clutter. **ⓘ** hints work on hover, keyboard focus or tap; Escape dismisses a tooltip. Section wiki links open documentation in a separate browser tab.

## Wiki

| Key or control | Result |
| --- | --- |
| Command/Ctrl + K | Focus and select the wiki search field |
| / | Focus search when not typing |
| Escape in search | Clear the query and return to browsing |
| Enter in search | Open the first matching result |
| Tab / Shift + Tab | Move through search results, navigation and article links |
| Browser Back / Forward | Retrace page and section navigation |
| Open in tab | Open the current article outside the embedded panel |

Search combines words across the whole page and ranks title/heading matches first. Results include a matching passage and link to its section when possible. The reader also provides Topics and A–Z navigation, breadcrumbs, page contents, subtopics, related entries, Linked from backlinks and a Markdown source link. Exact entry-name searches open that entry; passage matches open the matching section. Legacy section links follow entries moved into their own pages.
