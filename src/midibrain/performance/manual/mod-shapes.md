# Shape

**Open:** select a MOD → **Shape**.

Shape determines the source signal generated by [MOD](modulation.md). Its output then passes through source/connection amounts to a parameter, another MOD or a keyboard setting. A shape does not choose an output device by itself.

## Periodic shapes

| Shape | Source movement |
| --- | --- |
| sine | Smooth alternating positive/negative cycle |
| triangle | Linear rise and fall between extremes |
| saw up | Linear rise, then a jump back down |
| saw down | Linear fall, then a jump back up |
| square | Alternates between its positive and negative levels |

These shapes are bipolar. **Start phase**, 0–360°, chooses a point in the cycle. Free timing sets Hz; synced timing sets cycle length in quarter-note beats. Playback chooses continuous loop, triggered loop or one-shot. [MOD](modulation.md#playback) describes those choices.

## random

Random is sample-and-hold: each source cycle chooses a value between −1 and +1. **Slew**, 0–1, blends toward the new target during a fraction of that cycle. Zero changes immediately; larger slew spends more of the cycle moving toward the target.

Random uses Slew instead of Start phase. A [MOD → MOD](mod-mod.md) phase connection therefore affects slew when the target shape is random. The display samples source values; it is not a full MIDI-output recording.

## envelope

Envelope is a positive gate source. Selecting it in the Patch inspector chooses gate playback and free timing. Attack rises toward the active gate's strength; release moves back toward zero after the last gate is released.

| Field | Effect |
| --- | --- |
| Attack | Rise time; Patch slider 0–2000 ms |
| Release | Fall time; Patch slider 0–2000 ms |
| Velocity | Scale note strength from played velocity, or use full strength |
| Velocity curve | Exponent 0.1–8 shaping that strength |
| Max hold (ms) | Expire unreleased gates, 100–600000 ms |

The configuration model accepts attack/release up to 10000 ms; an imported value may be outside the narrower Patch slider span. Live MOD-to-MOD release offsets also clamp to the engine bounds.

With multiple gates, the strongest held gate sets the target; release of one note does not erase others. Repeated notes are tracked. See [Triggers / gates](triggers.md) for input matching and [sidechain ducking](sidechain.md) for an example rather than a separate source type.
